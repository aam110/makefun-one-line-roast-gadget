Bounty page: https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610

## Run

```sh
node main.ts
```

This writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
